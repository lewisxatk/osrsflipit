# OSRS FlipIt

A Vite + React OSRS Grand Exchange analytics site using the RuneScape Wiki prices API.

## Updated features

- Clear-search X button on the Market search field.
- Clickable OSRS FlipIt logo returns to Market.
- Item charts with 24h, 48h, weekly, monthly and 6-month ranges.
- Detailed buy/sell chart with black buy line, red sell line, grid, axis labels and hover tooltip showing date/time and both prices.
- Custom Market filters with Match all / Match any and operators including greater than, equal to, greater/equal, less than and less/equal.
- Local filter profiles that can be named and loaded later.
- Item max GE buy limit displayed on the item panel.
- Item icons shown beside item names.
- Movers expanded to the top 50 with price/volume/direction filters and sorting.
- Alert notifications are clickable and open the item's 48-hour chart.
- Market results display 30 items initially with a subtle Load more button.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
