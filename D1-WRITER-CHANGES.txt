D1 WRITER CHANGE SUMMARY — V56

- Browser live price rendering remains on the RuneScape Wiki prices API proxy. D1 does not replace live prices.
- The Worker cron wakes every minute for alert processing, but site-wide data jobs now check the market_sync timestamp first and return early until the 15-minute sync window is due.
- D1 current-market cache is limited to 25 liquid items per pass.
- Item mapping ingestion advances 25 records per pass, with conditional metadata upserts that avoid rewriting unchanged items.
- Event detection is capped at 8 meaningful price-drop/crash rows per pass; hourly behavioural rows are capped at 30 liquid records per pass.
- Rich OSRSBox and OSRS Wiki content syncs are gated to longer intervals.
- Internal ingestion governor remains 7,000 estimated rows per UTC day. It is an application-side safety estimate, not Cloudflare's official usage metric.
- Authenticated cloud sync skips unchanged saved data.
- `/api/data/health` reports D1 table counts, the pause flag, last market-sync timestamp/age, metadata and the internal writer estimate.
- Emergency stop affects scheduled OSRS site-wide data ingestion and manual `/api/data/sync`; it does not stop live price API reads, user/account writes or Discord alert cron.
- Migrations 0001–0005 are retained; no tables are dropped and no saved data is deleted.
